# Projekt: Trigger-Tagebuch

- Web-App (PWA) mit React, TypeScript und Vite
- Paketmanager ist Bun: immer `bun install`, `bun run ...` und `bunx` verwenden, nie npm oder yarn
- Daten nur lokal im Browser (IndexedDB mit Dexie), keine Server, keine Tracker
- Alle Texte in der Oberfläche auf Deutsch
- Die App muss auf dem Handy gut bedienbar sein
- Arbeite in kleinen Schritten und erkläre kurz, was du geändert hast
- Führe nach jeder Änderung Build und Tests aus
- Der Nutzer ist Programmieranfänger: erkläre Befehle verständlich
- Keine echten Gesundheitsdaten, Exporte oder Backups ins Repository (CSV/JSON in .gitignore)
